# Getting help

DLGE Player is in an early phase.
The player does not run the game yet, so most help today is about the tools
and the formats.

## Understand the project

- [README.md](README.md) says what the project is and what state it is in.
- [docs/roadmap.md](docs/roadmap.md) holds the order of the work, and the
  test that ends each phase.
- [docs/formats.md](docs/formats.md) describes the files of the game.
- [docs/decisions.md](docs/decisions.md) holds each decision and its reason.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository, human or agent.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/DLGEPlayer/issues) first, in case
  somebody has already asked.
- If you found a bug, open a bug report.
- If you want a feature, open a feature request.

When you report a problem with a file, give the command, the full output, and
the name and the size of the file.
Do not attach the file. The repository and its issues never hold game data.

Do not use the issue tracker for security problems.
See [SECURITY.md](SECURITY.md) for how to report those privately.
